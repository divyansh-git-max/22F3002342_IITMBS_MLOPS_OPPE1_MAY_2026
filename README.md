# 22F3002342 IITM BS MLOPS OPPE-1 (May 2026)

Stock movement prediction pipeline using DVC, Feast, MLflow, pytest, and GitHub Actions.

## Project Overview

- Data versions are tracked with DVC (`data/v0.dvc`, `data/v1.dvc`).
- Rolling features are generated by `scripts/prepare_features.py`.
- Feature definitions are managed in `feast_repo/`.
- Model training and model registry updates are handled by `scripts/train.py`.
- Inference helpers are available in `scripts/infer.py` and `scripts/inference.py`.
- CI runs tests and evaluation via `.github/workflows/ci.yml`.

## Environment Setup (Windows PowerShell)

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

If interpreter mismatch occurs, use explicit venv python:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Common Commands

### 1) Prepare features + apply Feast

```powershell
.\.venv\Scripts\python.exe scripts\prepare_features.py v0
```

For v0+v1 feature preparation:

```powershell
.\.venv\Scripts\python.exe scripts\prepare_features.py v1
```

### 2) Train model and register runs in MLflow

```powershell
.\.venv\Scripts\python.exe scripts\train.py
```

### 3) Run inference CLI

`infer.py` expects exactly 2 features:

```powershell
.\.venv\Scripts\python.exe scripts\infer.py 340.0 1000.0
```

Compatibility entrypoint:

```powershell
.\.venv\Scripts\python.exe scripts\inference.py 340.0 1000.0
```

### 4) Run tests

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_infer.py -q
```

## CI Workflow Notes

Workflow file: `.github/workflows/ci.yml`

CI includes a fast evaluation mode to reduce runtime:

- `CI_EVAL_USE_MLFLOW=false`: skips remote MLflow model fetch.
- `CI_EVAL_MAX_ROWS_PER_STOCK=25000`: caps rows processed per stock in evaluation.

The script used in CI is `scripts/ci_evaluate.py`.

## Troubleshooting

### `No module named feast`

Use venv python directly:

```powershell
.\.venv\Scripts\python.exe scripts\prepare_features.py v0
```

### Feast CLI invocation issue with `python -m feast`

This repo calls Feast through the venv-installed CLI entrypoint from scripts; avoid manually relying on `python -m feast`.

### Slow CI evaluation

Use fast mode env vars (already set in workflow) or reduce `CI_EVAL_MAX_ROWS_PER_STOCK` further.
